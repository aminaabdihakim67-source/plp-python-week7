# Week 7 Assignment: My Notes & The Report Builder

## Files
- `my_notes.py` - Writes, appends, reads, and counts notes.
- `my_notes.txt` - Stores the four notes created by my_notes.py.
- `report_builder.py` - Reads learner CSV data and builds a report.
- `hubs.csv` - Contains learner names, hub names, and scores.
- `report.txt` - Generated learner report with totals, passes, failures, and average.
- `report_screenshot.png` - Screenshot of the generated report.
- `notes_screenshot.png` - Screenshot of the notes program running.
- `README.md` - Describes the assignment files and explains append mode.

## What happens if "a" is changed to "w"?

Changing `"a"` to `"w"` would overwrite the existing notes file instead of adding to it. The first three notes would be erased, leaving only the fourth note.
